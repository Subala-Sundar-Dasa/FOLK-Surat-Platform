# Knowledge-base working copy

This directory contains the curated Markdown Prabhupada corpus approved for the private FOLK Surat repository.

## Contents

- `prabhupada-corpus/books/`: 237 Markdown files.
- `prabhupada-corpus/correspondence/`: 250 Markdown files.
- `prabhupada-corpus/audio-transcripts/`: 250 Markdown files.
- `CORPUS_MANIFEST.csv`: repository-relative path, byte length, and SHA-256 for all 737 files.

The source copy was read from the existing local FOLK web workspace. The archived originals on the D drive were not changed. Common secret-token/private-key patterns were scanned before copying and no matches were found. This does not grant permission to publish or upload the corpus to an external retrieval service.

Before updating the corpus, repeat the secret scan, verify that no real-student or unrelated personal data is included, regenerate the checksum manifest, and document the change.
