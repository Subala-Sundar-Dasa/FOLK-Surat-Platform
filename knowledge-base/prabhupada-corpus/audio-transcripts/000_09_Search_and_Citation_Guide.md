# NotebookLM Search and Citation Guide

Search by combining dimensions rather than using one broad word.

Examples:

- “Find events tagged `siddhanta:jiva-tattva` where materialism is refuted.”
- “Show personal guidance about marriage, excluding general lectures on gṛhastha life.”
- “Give passages connected with Bhagavad Gita As It Is 2.13 and cite the event code.”
- “Compare universal principles with local management instructions about temple leadership.”
- “Find philosophical discussions where an opposing position is quoted and then corrected.”

For every quotation, request the title, event code, date/place, speaker, and normalized scriptural reference. The semantic metadata helps retrieval; the citation preview should still point to the spoken transcript immediately below it.
