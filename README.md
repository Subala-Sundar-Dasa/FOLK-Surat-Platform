# FOLK Surat Platform

Private coordination and knowledge repository for the FOLK Surat student-growth platform. It is the shared source of truth for Claude Code, Codex, and human developers working across the student app, guide app, web CRM, Supabase backend, integrations, and the Prabhupada-grounded knowledge system.

## Start here

1. Read [`CLAUDE.md`](CLAUDE.md) or [`AGENTS.md`](AGENTS.md).
2. Read [`docs/CURRENT_STATUS.md`](docs/CURRENT_STATUS.md).
3. Choose work from [`planning/backlog.yaml`](planning/backlog.yaml).
4. Confirm the approval boundary in [`docs/SECURITY_AND_PRIVACY.md`](docs/SECURITY_AND_PRIVACY.md).
