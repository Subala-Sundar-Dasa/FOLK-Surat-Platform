# Agent instructions

This repository coordinates three implementation repositories. Before acting, read `CLAUDE.md` and the linked status documents completely.

Prefer evidence-backed, reversible work. Do not infer authorization beyond the explicit approval boundary. Ask before foundational product changes. Never silently alter the spiritual-growth model, targets, roles, notification policy, or corpus-grounding rules.

For every completed unit: run relevant checks, document what changed, list remaining risks, and leave the next agent an exact first command or file to inspect.
